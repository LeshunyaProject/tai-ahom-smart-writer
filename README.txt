TAI AHOM SMART WRITER — Prototype 0.1

Files:
- index.html: prototype interface
- manifest.json: PWA metadata
- sw.js: basic offline cache

Important:
1. This is a starter prototype, not a finished translator.
2. No unverified Tai Ahom spellings, translations, or pronunciations are invented.
3. Voice input uses browser Speech Recognition where supported. It transcribes a selected supported language; it does NOT yet recognize Tai Ahom speech or translate it.
4. To install as a PWA, upload these files to an HTTPS host. Opening index.html directly on a phone does not enable full PWA installation/offline service-worker behavior.
5. Add only source-checked dictionary records and script mappings after reviewing original pages and confirming glyphs.
